# Security policy

Appraisal Map handles private appraisal records. Please do not open a public issue containing credentials, report contents, personal information, or exploit details.

## Reporting a concern

Use the repository’s private **Security → Report a vulnerability** form. If private vulnerability reporting is not available, contact the repository owner through an established private channel before sharing details.

Include the affected screen or component, the impact, safe reproduction steps, and whether any real data may have been exposed. Do not download, alter, or retain records while investigating.

## Supported version

Only the current production deployment from the default branch is supported. Security fixes should be applied there promptly after verification.
